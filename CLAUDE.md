## Lecture-notes port (branch `course-diffgeo-gr`)

The course section `notes/diffgeo-gr/` is generated from the LaTeX notes "From Differential Geometry to General Relativity". Brief: `_port/KICKOFF.md`. **Start from `_port/PROGRESS.md`** (ledger, next action), then `_port/DECISIONS.md` (how and why), `_port/PLAN.md`, `_port/REVIEW.md`. Model/delegation rules: `_port/MODELS.md`.

Rules (not negotiable; full text in KICKOFF.md):
1. The notes' content is never reworded, reordered or corrected. Typos and slips go to `_port/REVIEW.md`.
2. Pages are generated by the converter (`_port/convert/`). Never edit a generated file (`notes/diffgeo-gr/**/*.qmd` except `index.qmd`, `_sidebar.yml`, `_generated/`, `figures/`, `docs/`); teach the converter instead. A construct it does not know stops that page with `file:line`.
3. Math source is the notes' source; numbers come from the LaTeX build (`main.port`, `main.aux`), never from a counter of ours.
4. The notes directory is read-only. Compile only the scratch copy. `git -C <notes>/.. status --short` must print nothing.
5. Work only on `course-diffgeo-gr`. Never push, merge or rewrite history. Never `git add -A` / `commit -a`: ~120 files show mode-only changes; stage explicit paths (DECISIONS D22).
6. Outside `notes/diffgeo-gr/` only: the navbar entry and sidebar include in `_quarto.yml`, and the "Read online" buttons in `teaching_and_projects.qmd`.
7. Web-only additions are visibly a web layer (`dg-web`, "Interactive" frame); every sentence written for them is listed in `_port/REVIEW.md`.

Commands (run from the repo root):
```bash
_port/tex/build_scratch.sh              # copy the notes to _port/.work and compile with numbering hooks (~4 min; needed after the LaTeX changes)
python3 _port/convert/build.py --status # which pages convert, and why not (fast, writes nothing)
python3 _port/convert/build.py          # regenerate pages, sidebar, figures      (--strict: fail if any page is pending)
node _port/tools/math_check.mjs         # typeset every equation of the notes with the site's math config
quarto render notes/diffgeo-gr          # render the course pages into docs/ (~1 min);  `quarto render` for the whole site
quarto preview                          # local preview at http://localhost:<port>/notes/diffgeo-gr/
python3 _port/tools/make_inventory.py   # refresh _port/INVENTORY.md
```
