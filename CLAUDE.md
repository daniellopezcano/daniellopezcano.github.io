## Lecture-notes port (branch `course-diffgeo-gr`)

The course section `notes/diffgeo-gr/` is generated from the LaTeX notes "From Differential Geometry to General Relativity". Briefs: `_port/KICKOFF.md`, then `_port/REDESIGN.md` (phase 2; it wins where they differ). **Start from `_port/PROGRESS.md`** (ledger, next action), then `_port/DECISIONS.md` (how and why; D29–D37 are phase 2), `_port/DESIGN.md`, `_port/PLAN.md`, `_port/REVIEW.md`. Model/delegation rules: `_port/MODELS.md`.

Rules (not negotiable; full text in KICKOFF.md):
1. The notes' content is never reworded, reordered or corrected. Typos and slips go to `_port/REVIEW.md`.
2. Pages are generated by the converter (`_port/convert/`). Never edit a generated file (`notes/diffgeo-gr/**/*.html`, `assets/search.json`, `assets/labels.json`, `assets/fonts/`, `figures/`, `docs/`); teach the converter instead (page shell: `_port/convert/shell.py`, landing page: `_port/convert/templates/landing.html`). A construct it does not know stops that page with `file:line`.
3. Math source is the notes' source; numbers come from the LaTeX build (`main.port`, `main.aux`), never from a counter of ours.
4. The notes directory is read-only. Compile only the scratch copy. `git -C <notes>/.. status --short` must print nothing.
5. Work only on `course-diffgeo-gr`. Never push, merge or rewrite history (the pilot was merged and pushed once, by the author's one-off authorisation of 2026-11-15; that does not extend to anything else). Never `git add -A` / `commit -a`: ~120 files show mode-only changes; stage explicit paths (DECISIONS D22).
6. Outside `notes/diffgeo-gr/` only: the navbar entry, the course `resources` glob and the `post-render` line in `_quarto.yml`, and the "Read online" buttons in `teaching_and_projects.qmd`.
7. Web-only additions are visibly a web layer (`dg-web`, "Interactive" frame); every sentence written for them is listed in `_port/REVIEW.md`.

Commands (run from the repo root):
```bash
_port/tex/build_scratch.sh              # copy the notes to _port/.work and compile with numbering hooks (~4 min; needed after the LaTeX changes)
python3 _port/convert/build.py --status # which pages convert, and why not (fast, writes nothing)
python3 _port/convert/build.py --chapters # what the chapter opening pages show: roadmap and related B/C items (D38; writes nothing)
python3 _port/convert/build.py          # regenerate the course pages (complete HTML), figures, search index (--strict: fail if any page is pending)
node _port/tools/math_check.mjs         # typeset every equation of the notes with the site's math config
_port/build.sh [--no-tex]               # scratch build + converter + copy of the course into docs/ (+ post_render.py); seconds with --no-tex
_port/build.sh --site [--no-tex]        # ... with a full `quarto render` of the site (copies the course pages, runs _port/tools/post_render.py)
quarto preview                          # local preview at http://localhost:<port>/notes/diffgeo-gr/
node _port/tools/test_page_script.mjs && node _port/tools/test_interactives.mjs   # behaviour tests in a headless browser (after a build)
python3 _port/tools/make_inventory.py   # refresh _port/INVENTORY.md
bash _port/check.sh                     # all definition-of-done checks; ends with ALL CHECKS PASSED or the failures (--no-render: reuse docs/)
_port/design/preview.sh                 # the three design-direction prototypes at http://localhost:4321/design/ (record of the choice; not part of the build)
```
