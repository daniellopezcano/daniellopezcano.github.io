2.2 Vector Space, Dual Space, and Tensor Space

Chapter 2 • Vector Spaces

2.2 Vector Space, Dual Space, and Tensor Space

We now formally define the concept of an \(\mathbb{R}\)-vector space, along with the related notions of linear maps, isomorphisms, and the dual vector space (rows 3 and 4 of Figure 1.2). Note that, at this stage, the definitions are purely algebraic and do not rely on any choice of basis. See appendices C.1.1 & C.1.2 for concrete examples illustrating these definitions employing polynomials.

  • An \(\mathbb{R}\)-vector space is the triplet \((V, \oplus, \odot)\) equipped with the Field \((\mathbb{R}, +, \cdot)\). The doublet \((V, \oplus)\) forms an Abelian group, and the s-multiplication operator \(\odot: \mathbb{R} \times V \to V\) satisfies (considering \(\mathcal{X}, \mathcal{Y} \in V\), elements of the vector space, known as vectors, and \(\alpha, \beta \in \mathbb{R}\)):

    1. Associativity (w.r.t \(\cdot, \odot\)): \((\alpha \cdot \beta) \odot \mathcal{X} = \alpha \odot (\beta \odot \mathcal{X})\),

    2. Distributive 1: \((\alpha + \beta) \odot \mathcal{X} = (\alpha \odot \mathcal{X}) \oplus (\beta \odot \mathcal{X})\),

    3. Distributive 2: \(\alpha \odot (\mathcal{X} \oplus \mathcal{Y}) = (\alpha \odot \mathcal{X}) \oplus (\alpha \odot \mathcal{Y})\),

    4. Unitarity / Neutral element / Identity (w.r.t \(\odot\)): \(\exists 1 \in \mathbb{R}\) such that \(1 \odot \mathcal{X} = \mathcal{X} \odot 1 = \mathcal{X}\).

  • Let \((V, \oplus_V, \odot_V)\) and \((W, \oplus_W, \odot_W)\) be vector spaces. The map \(\phi : V \to W\) is linear (w.r.t. the vector spaces we have defined, also denoted as \(\phi : V \overset{\sim}{\longrightarrow} W\)) \(\iff \forall \mathcal{X}, \mathcal{Y} \in V; \, \forall \alpha \in \mathbb{R}\):

    1. \( \phi(\mathcal{X} \oplus_V \mathcal{Y}) = \phi(\mathcal{X}) \oplus_W \phi(\mathcal{Y}) \), and

    2. \( \phi(\alpha \odot_V \mathcal{X}) = \alpha \odot_W \phi(\mathcal{X}) \).

  • Given two \(\mathbb{R}\)-vector spaces \((V, \oplus_V, \odot_V)\) and \((W, \oplus_W, \odot_W)\), a map \(\phi : V \longrightarrow W\) is a (vector space) isomorphism if it is linear and bijective, hence invertible. If such a map exists, we say that the vector spaces \(V\) and \(W\) are isomorphic, and we write \(V \cong W\). Intuitively, this means that \(V\) and \(W\) have the same structure as vector spaces.

  • The Vector Space of Homomorphisms between two vector spaces \((V, \oplus_V, \odot_V)\) and \((W, \oplus_W, \odot_W)\) is the triplet conformed by the set \(\text{Hom}(V, W) := \{ \phi, \varphi : V \overset{\sim}{\longrightarrow} W \}\), and the operations: \[ \begin{aligned} &\begin{array}{c} \textbf{Addition } \oplus_H: \\[6pt] \begin{aligned} \oplus_H : \text{Hom}(V, W) \times \text{Hom}(V, W) &\longrightarrow \text{Hom}(V, W) \\ (\phi, \varphi) &\longmapsto \phi \oplus_H \varphi \end{aligned} \\[6pt] \text{with } (\phi \oplus_H \varphi)(v) := \phi(v) \oplus_W \varphi(v). \end{array} \quad &\begin{array}{c} \textbf{s-multiplication } \odot_H: \\[6pt] \begin{aligned} \odot_H : \mathbb{R} \times \text{Hom}(V, W) &\longrightarrow \text{Hom}(V, W) \\ (\lambda, \phi) &\longmapsto \lambda \odot_H \phi \end{aligned} \\[6pt] \text{with } (\lambda \odot_H \phi)(v) := \lambda \odot_W \phi(v). \end{array} \end{aligned} \]

  • Given a vector space \((V, \oplus, \odot)\), we define its Dual Vector Space as \((V^* , \oplus^*, \odot^*)\), with \(V^* := \text{Hom}(V, \mathbb{R}) := \{ \phi : V \overset{\sim}{\longrightarrow} \mathbb{R} \}\), and the addition and s-multiplication operators, \(\oplus^*\) and \(\odot^*\), following the associatted homomorphic definitions above. We will denote with \(\mathsf{X}, \mathsf{Y}\) elements of the dual vector space \(V^*\) known as covectors.

  • Given a vector space \((V, \oplus, \odot)\) and its dual vector space \((V^*, \oplus^*, \odot^*)\), we define the \((r,s)\)-tensor space as the triplet \(\left( {T}^{(r,s)}, \oplus_T, \odot_T \right)\), where \({T}^{(r,s)}\) is the set of all maps of the form2 3: \begin{align*} T \colon \underbrace{V^* \times \dots \times V^*}_{r \text{-times}} \times \underbrace{V \times \dots \times V}_{s \text{-times}} &\xlongrightarrow{\substack{\sim \\ \dots \\ \sim}} \mathbb{R} \\ \left( \mathsf{X}^{(1)}, \dots, \mathsf{X}^{(r)}, \mathcal{X}^{(1)}, \dots, \mathcal{X}^{(s)} \right) &\longmapsto T \left( \mathsf{X}^{(1)}, \dots, \mathsf{X}^{(r)}, \mathcal{X}^{(1)}, \dots, \mathcal{X}^{(s)} \right), \end{align*} with the property that \(T\) is multilinear, i.e., it is \(\mathbb{R}\)-linear with respect to each of its \(r + s\) slots independently. The multilinearity condition explicitly reads:

    • For any covector slot \(i \in \{1, \dots, r\}\): \[ \begin{aligned} T \left( \dots,\; \alpha \odot^* \mathsf{X}^{(i)} \oplus^* \mathsf{Y}^{(i)},\; \dots;\; \dots \right) = \alpha \cdot T \left( \dots,\; \mathsf{X}^{(i)},\; \dots;\; \dots \right) + T \left( \dots,\; \mathsf{Y}^{(i)},\; \dots;\; \dots \right), \end{aligned} \] for any \(\alpha \in \mathbb{R}\) and any \(\mathsf{X}^{(i)}, \mathsf{Y}^{(i)} \in V^*\).

    • Similarly, for any vector slot \(j \in \{1, \dots, s\}\): \[ \begin{aligned} T \left( \dots;\; \dots,\; \alpha \odot \mathcal{X}^{(j)} \oplus \mathcal{Y}^{(j)},\; \dots \right) = \alpha \cdot T \left( \dots;\; \dots,\; \mathcal{X}^{(j)},\; \dots \right) + T \left( \dots;\; \dots,\; \mathcal{Y}^{(j)},\; \dots \right), \end{aligned} \] for any \(\alpha \in \mathbb{R}\) and any \(\mathcal{X}^{(j)}, \mathcal{Y}^{(j)} \in V\).

    The addition \(\oplus_T\) and the s-multiplication \(\odot_T\) in the \((r,s)\)-tensor space \(\left( {T}^{(r,s)}, \oplus_T, \odot_T \right)\) are the defined as: \[ \begin{aligned} &\begin{array}{c} \begin{aligned} \oplus_T : {T}^{(r,s)} \times {T}^{(r,s)} &\longrightarrow {T}^{(r,s)} \\ (T_1, T_2) &\longmapsto T_1 \oplus_T T_2 \end{aligned} \\[6pt] \text{with } (T_1 \oplus_T T_2)(\dots) := T_1(\dots) + T_2(\dots). \end{array} \quad &\begin{array}{c} \begin{aligned} \odot_T : \mathbb{R} \times {T}^{(r,s)} &\longrightarrow {T}^{(r,s)} \\ (\alpha, T) &\longmapsto \alpha \odot_T T \end{aligned} \\[6pt] \text{with } (\alpha \odot_T T)(\dots) := \alpha \cdot T(\dots). \end{array} \end{aligned} \]

  • Given two \(\mathbb{R}\)-vector spaces \(\left( V, \oplus_V, \odot_V \right)\) and \(\left( W, \oplus_W, \odot_W \right)\), we define their tensor product as the \(\mathbb{R}\)-vector space \(\left( V \otimes W, \oplus_\otimes, \odot_\otimes \right)\), whose elements are finite sums \(\tau = \sum_{k} \alpha_k \, (v_k \otimes w_k)\) of simple tensors \(v_k \otimes w_k\), with \(\alpha_k \in \mathbb{R}\), and whose operations act term by term: \[ \begin{aligned} &\begin{array}{c} \textbf{Addition} \; \oplus_\otimes: \\[6pt] \begin{aligned} \oplus_\otimes : (V \otimes W) \times (V \otimes W) &\longrightarrow V \otimes W \\[2pt] (\tau_1,\; \tau_2) &\longmapsto \tau_1 \oplus_\otimes \tau_2 \end{aligned} \\[6pt] \text{with } \displaystyle\sum_{k} \alpha_k (v_k \otimes w_k) \oplus_\otimes \sum_{l} \beta_l (v'_l \otimes w'_l) := \sum_{k} \alpha_k (v_k \otimes w_k) + \sum_{l} \beta_l (v'_l \otimes w'_l). \end{array} \end{aligned} \] \[ \begin{aligned} &\begin{array}{c} \textbf{s-multiplication} \; \odot_\otimes: \\[6pt] \begin{aligned} \odot_\otimes : \mathbb{R} \times (V \otimes W) &\longrightarrow V \otimes W \\[2pt] (\alpha,\; \tau) &\longmapsto \alpha \odot_\otimes \tau \end{aligned} \\[6pt] \text{with } \alpha \odot_\otimes \displaystyle\sum_{k} \alpha_k (v_k \otimes w_k) := \sum_{k} (\alpha \cdot \alpha_k) (v_k \otimes w_k). \end{array} \end{aligned} \]

    Two such sums are regarded as the same element whenever one can be turned into the other using the bilinearity relations: \[ \begin{aligned} (v_1 \oplus_V v_2) \otimes w &= (v_1 \otimes w) \oplus_\otimes (v_2 \otimes w), \\[4pt] v \otimes (w_1 \oplus_W w_2) &= (v \otimes w_1) \oplus_\otimes (v \otimes w_2), \\[4pt] (\alpha \odot_V v) \otimes w &= \alpha \odot_\otimes (v \otimes w) = v \otimes (\alpha \odot_W w). \end{aligned} \] The general elements of \(V \otimes W\) are finite linear combinations: \[ \sum_{k} \alpha_k \odot_\otimes (v_k \otimes w_k), \quad \alpha_k \in \mathbb{R}. \] The tensor product formalizes the concept of bilinearity itself into a linear structure. This provides the algebraic backbone that generalizes naturally to multilinearity, which underlies the formal definition of tensors as higher-order linear maps. The tensor product enjoys the following structural properties:

    • Universal Property: For any bilinear map, \(B : V \times W \longrightarrow Z\), into a vector space \(Z\), there exists a unique linear map \(\widetilde{B} : V \otimes W \longrightarrow Z\) such that \(\widetilde{B} (v \otimes w) = B(v, w)\) for all \(v \in V\) and \(w \in W\).

    • Dimension Formula: If \(\dim V = m\) and \(\dim W = n\), then \(\dim ( V \otimes W ) = m \cdot n\). A basis is given by the set of tensor products of basis elements: \[ \{ \hat{x}_i \otimes \hat{y}_j \mid i=1,\dots,m;\; j=1,\dots,n \}, \] where \(\{\hat{x}_i\}\) and \(\{\hat{y}_j\}\) are bases of \(V\) and \(W\), respectively.

    • Associativity: Tensor products are associative up to canonical isomorphism: \((V_1 \otimes V_2) \otimes V_3 \cong V_1 \otimes (V_2 \otimes V_3)\). It is customary to omit parentheses and write unambiguously: \(V_1 \otimes V_2 \otimes V_3\).

    • Distributivity over Direct Sums: Tensor products distribute over direct sums: \[ (V_1 \oplus_V V_2) \otimes W \cong (V_1 \otimes W) \oplus_\otimes (V_2 \otimes W). \]

    • Duality Relation: There is a canonical isomorphism \(\text{Hom}(V \otimes W, \mathbb{R}) \cong \text{Bilin}(V \times W, \mathbb{R})\), where \(\text{Bilin}(V \times W, \mathbb{R})\) denotes the space of bilinear maps from \(V \times W\) to \(\mathbb{R}\).

  • An equivalent way to define an \((r,s)\)-tensor on a finite-dimensional vector space \((V, \oplus, \odot)\) is as an element of the tensor product space \[ T^{(r,s)} \cong \underbrace{V \otimes \dots \otimes V}_{r\text{-times}} \otimes \underbrace{V^* \otimes \dots \otimes V^*}_{s\text{-times}}. \] Note the order of the factors: the \(r\) covector slots of the multilinear map are matched by \(r\) copies of \(V\), and the \(s\) vector slots by \(s\) copies of \(V^*\). This is because a vector \(v \in V\) can eat covectors through the canonical identification \(V \cong (V^*)^*\) discussed in the next item, \(v(\mathsf{X}) \coloneqq \mathsf{X}(v)\), while a covector eats vectors directly. Accordingly, a simple tensor with \(v_1, \dots, v_r \in V\) and \(\mathsf{v}^1, \dots, \mathsf{v}^s \in V^*\) acts slot by slot, \[ \left( v_1 \otimes \dots \otimes v_r \otimes \mathsf{v}^1 \otimes \dots \otimes \mathsf{v}^s \right) \left( \mathsf{X}^{(1)}, \dots, \mathsf{X}^{(r)}, \mathcal{X}^{(1)}, \dots, \mathcal{X}^{(s)} \right) \coloneqq \mathsf{X}^{(1)}(v_1) \cdots \mathsf{X}^{(r)}(v_r) \cdot \mathsf{v}^1\big(\mathcal{X}^{(1)}\big) \cdots \mathsf{v}^s\big(\mathcal{X}^{(s)}\big), \] which is manifestly multilinear, and a general element of the tensor product space acts by extending this rule linearly (which is well defined by the universal property). The resulting linear map from the tensor product space to the space of multilinear maps defined above is an isomorphism when \(V\) is finite-dimensional: both spaces have dimension \(d^{\,r+s}\) and, as shown below, the images of simple tensors of basis elements span the space of multilinear maps. This is the precise sense in which both definitions are equivalent, and the reason for the symbol \(\cong\).

    In this definition, tensors are no longer described as multilinear maps, but rather as elements of a vector space constructed through tensor products. Both perspectives are fully equivalent: the first is often more intuitive for understanding the action of tensors, while the second is more algebraic and convenient for computations, particularly in component form.

  • We can also think of tensors as follows: Given a \((1,1)\)-tensor \begin{align*} T : V^* \times V &\;\xlongrightarrow{\substack{\sim \\ \sim}}\; \mathbb{R}\\ \left( \mathsf{X}, \mathcal{X} \right) &\longmapsto T\left( \mathsf{X}, \mathcal{X} \right). \end{align*} We can associate to any such tensor a linear map \begin{align*} \varphi_T :V &\;\xlongrightarrow{\sim}\; V\\ \mathcal{X} &\longmapsto \varphi_T(\mathcal{X}) \coloneqq T(\cdot, \mathcal{X}), \end{align*} where the dot “\(\cdot\)” indicates that the first slot is left open. More explicitly, the map \begin{align*} T(\cdot, \mathcal{X}) : V^* &\;\xlongrightarrow{\sim}\; \mathbb{R}\\ \mathsf{X} &\longmapsto T\left( \mathsf{X}, \mathcal{X} \right), \end{align*} is a linear map that can eat a covector \(\mathsf{X} \in V^*\) and return a real number. Hence, \(T(\cdot, \mathcal{X}) \in (V^*)^*\), that is, the dual of \(V^*\). In finite-dimensional vector spaces, there exists a canonical isomorphism \((V^*)^* \cong V\) which identifies \((V^*)^*\) with \(V\) itself 4. Therefore, \(T(\cdot, \mathcal{X})\) can be interpreted as an element of \(V\). In other words, the data of a \((1,1)\)-tensor, \(T : V^* \times V \xlongrightarrow{\substack{\sim \\ \sim}} \mathbb{R}\), is equivalent to the data of the linear map \(\varphi_T : V \xlongrightarrow{\sim} V\).

2

The indices enclosed in parentheses, such as \(\mathsf{X}^{(i)}\) or \(\mathcal{X}^{(j)}\), refer strictly to the position of the argument within the tensor map \(T\). This is a purely positional convention used for clarity when expressing properties like multilinearity. Don’t confuse this with coordinate or basis indices.

3

We can equivalently write \(T \in T^{(r,s)} := \text{Hom}(\underbrace{V^* \times \dots \times V^*}_{r\text{-times}} \times \underbrace{V \times \dots \times V}_{s\text{-times}}, \mathbb{R})\)

4

This identification holds because in finite-dimensional spaces, the double dual of any vector space is naturally isomorphic to the space itself. This is not generally true in infinite-dimensional settings, where the double dual can be strictly larger than the original space, unless additional conditions (like reflexivity) are satisfied.
